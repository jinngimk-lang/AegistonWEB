# 视觉签核单（visual-signoff）

> **用途**：放行条件 C2 规定「§12.3 的 `computed-style.spec` 与 `responsive.spec`
> 是自动守护，人工签核单是最终确认，两者都不可省」。本文件是那份人工签核单。
>
> **签核方式**：把 `ref/1.html` 与本站首页并排打开（同一浏览器、同一缩放比、
> 同一视口宽度），逐条勾选。自动化已覆盖的项在「自动」列标 ✅，
> 人工只需确认「看起来对不对」，不必重新测量。
